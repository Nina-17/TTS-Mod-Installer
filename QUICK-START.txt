🎲 TTS 本地图包魔法搬运工 v0.5.3 ✨

使用前：
1. 请先把发布 ZIP“全部解压”。
2. 双击解压后的“点我启动.cmd”。
3. 把一个或多个图包文件夹、ZIP 或 TTSMOD 拖进窗口，按 Enter。

安装器每次普通启动都会检查 GitHub 正式版更新：
- GitHub 直连失败时，会自动切换 gh-proxy.com 通道。
- 输入 U：下载、校验、自动更新并重新打开。
- 输入 S：本次跳过，继续安装图包。
- 断网或 GitHub 暂时不可用不会影响图包安装。

也可以：
- 把图包直接拖到“点我启动.cmd”图标上。
- 在安装器窗口输入 F，选择一个或多个压缩包。

安装器的日志、临时文件和更新备份都放在本文件夹的“运行数据”中。
把整个文件夹放在 D 盘，安装器自身的运行数据也会留在 D 盘。

安装器会自动寻找 TTS 当前使用的 Mods 目录，并执行合并覆盖：
- 覆盖同名文件。
- 保留目标中其他已有文件。
- 不会镜像删除其他 Mod。
- 复制时显示单行循环进度条和可爱颜文字，不会逐文件刷屏。
- 详细过程保存在“运行数据\Logs”。

如果提示 TTS 正在运行，请先退出游戏。
如果提示需要管理员权限，请确认 Windows UAC。

ZIP、TTSMOD、7Z 和 RAR 都可以直接使用，不需要另行安装 7-Zip。

详细说明见 README.md。
