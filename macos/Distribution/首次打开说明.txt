首次打开说明
============

本应用使用免费开发者账号条件下的 ad-hoc 签名，没有 Apple Developer ID 公证。

如果双击后提示 Apple 无法检查应用是否包含恶意软件：

1. 先尝试打开一次，然后关闭提示。
2. 打开“系统设置”→“隐私与安全性”。
3. 在安全性区域找到 TTS Mod Installer，点击“仍要打开”。
4. 输入当前 Mac 登录密码并确认。

系统会把这个版本保存为例外，之后可以正常双击打开。

请只从项目官方 GitHub Release 下载，并核对同名 .sha256 文件。
项目地址：https://github.com/Nina-17/TTS-Mod-Installer
